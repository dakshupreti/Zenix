# 🤖 Zenix

**Zenix** is a personal AI desktop assistant built in Python. It is designed to automate everyday tasks, answer commands, search the web, remember information, and eventually become a full-featured voice assistant inspired by assistants like Jarvis.

---

## ✨ Current Features

* 🗣️ Voice responses
* 🧠 Memory system
* ⏰ Current time
* 📅 Current date
* 🧮 Calculator
* 🌐 Google Search
* ▶️ YouTube Search
* 💻 Open desktop applications
* 🌍 Open websites

---

## 🛠️ Technologies Used

* Python 3.13
* pyttsx3
* JSON
* Git
* GitHub

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/dakshupreti/Zenix.git
```

2. Move into the project folder:

```bash
cd Zenix
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the assistant:

```bash
python main.py
```
